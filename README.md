# ODU Stats Midterm Pretest Trainer

A 44-question intro statistics pretest drill in a single dark, mobile-first HTML page that works offline.

**Live:** https://ellisdeeman.github.io/stats-pretest-trainer/

## Features

- Start quiz / retry missed / review all
- One question at a time with progress bar
- Instant correct/wrong highlight + explanation
- Score screen and localStorage so results survive a refresh
- Dark theme, iPhone-friendly tap targets
- One HTML file, no login, no backend

## Add to your iPhone home screen

1. Open https://ellisdeeman.github.io/stats-pretest-trainer/ in Safari.
2. Tap the **Share** button.
3. Tap **Add to Home Screen**.

It then launches full-screen like an app, with its own icon.
